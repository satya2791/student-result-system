# 🎓 Student Result System

Don't know how to calculate your results? Let's remove the confusion!

## 📌 About the Project

Student Result System is a simple and interactive web application that helps students calculate their academic results easily.

Users can enter their name, number of subjects, total marks, and individual subject marks. The application calculates the obtained marks, percentage, and grade automatically.

## ✨ Features

- Enter student details.
- Specify the number of subjects.
- Dynamically generate input fields for subject marks.
- Validate student details and marks.
- Automatically calculate total obtained marks.
- Calculate percentage.
- Display the student's grade.
- Start Over option to calculate another result.
- Responsive user interface.

## 🛠️ Technologies Used

- **HTML5** – Application structure.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Dynamic elements, input validation, and result calculations.

## 🚀 How to Use

1. Enter the student's name.
2. Enter the number of subjects.
3. Enter the total marks.
4. Click Submit.
5. Enter the marks obtained in each subject.
6. Click Submit to view the result.
7. View the total marks, percentage, and grade.
8. Click Start Over to calculate another result.
